# File Utils

Utility functions for working with files.

---

## `formatFileSize`

Formats a byte count as a human-readable file size string in KB or MB.

```ts
import { formatFileSize } from '@team-hermes/react-components'

formatFileSize(512) // "0.5 KB"
formatFileSize(1048576) // "1.0 MB"
formatFileSize(2621440) // "2.5 MB"
```

## `isAcceptedFileType`

Checks whether a file matches an `accept` string. Mirrors the native `accept` attribute matching (extensions, MIME types, wildcards). Returns `true` when `accept` is empty.

```ts
import { isAcceptedFileType } from '@team-hermes/react-components'

isAcceptedFileType(file, '.pdf') // true if the name ends with .pdf
isAcceptedFileType(file, 'image/*, .pdf') // wildcard MIME types and extensions
isAcceptedFileType(file) // true
```
