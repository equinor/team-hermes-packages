# Object Utils

Utility functions for reading, writing, and deleting nested properties using dot/bracket notation paths.

---

## `deepSet`

Sets a nested value in an object using a dot/bracket notation path. Intermediate objects and arrays are created automatically.

```ts
import { deepSet } from '@team-hermes/react-components'

const obj: Record<string, any> = {}
deepSet(obj, 'a.b.c', 42)
// obj → { a: { b: { c: 42 } } }

deepSet(obj, 'items[0].name', 'first')
// obj → { a: { b: { c: 42 } }, items: [{ name: "first" }] }
```

## `deleteByPath`

Deletes a property from an object at a dot/bracket notation path.

```ts
import { deleteByPath } from '@team-hermes/react-components'

const obj = { a: { b: { c: 42 } } }
deleteByPath(obj, 'a.b.c') // true — obj is now { a: { b: {} } }
deleteByPath(obj, 'x.y.z') // false — path does not exist
```

## `getNestedValue`

Retrieves a nested value from an object using a dot notation path, with an optional default.

```ts
import { getNestedValue } from '@team-hermes/react-components'

const obj = { a: { b: { c: 42 } } }
getNestedValue(obj, 'a.b.c') // 42
getNestedValue(obj, 'a.x.y') // null
getNestedValue(obj, 'a.x.y', 'fallback') // "fallback"
```
