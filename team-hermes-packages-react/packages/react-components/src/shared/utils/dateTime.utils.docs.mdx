# DateTime Utils

Utility functions for formatting and comparing dates and times.

---

## `timeAgo`

Returns a human-readable relative time string (e.g. "2 days ago", "40 minutes ago"). Uses `Intl.RelativeTimeFormat` under the hood.

```ts
import { timeAgo } from '@team-hermes/react-components'

timeAgo('2026-08-09T12:00:00Z') // "2 days ago"
timeAgo(new Date().toISOString()) // "Now"
```

**Returns** `string` — A relative time string, or `"Now"` if less than 1 second has elapsed.

## `isWithinLastHours`

Checks whether a date string falls within the last _n_ hours from now.

```ts
import { isWithinLastHours } from '@team-hermes/react-components'

isWithinLastHours('2026-08-11T10:00:00Z', 2) // true if within 2 hours
```

## `formatDate`

Formats a date as `dd/mm/yyyy`. Returns the original input as a string if parsing fails.

```ts
import { formatDate } from '@team-hermes/react-components'

formatDate('2026-08-11T00:00:00Z') // "11/08/2026"
formatDate(new Date(2026, 7, 11)) // "11/08/2026"
formatDate('not-a-date') // "not-a-date"
```

## `formatYear`

Extracts and returns the year from an epoch-millisecond number or an ISO date string. Useful for formatting histogram bucket keys.

```ts
import { formatYear } from '@team-hermes/react-components'

formatYear(1786147200000) // "2026"
formatYear('2026-08-11T00:00:00Z') // "2026"
formatYear(undefined) // "—"
```

**Returns** `string` — The four-digit year, or `"—"` if the input is nullish.

## `formatDateForInput`

Formats a date string into `yyyy-MM-dd` for use as a value in `<input type="date">` elements.

```ts
import { formatDateForInput } from '@team-hermes/react-components'

formatDateForInput('2026-08-11T00:00:00Z') // "2026-08-11"
formatDateForInput(null) // null
```
