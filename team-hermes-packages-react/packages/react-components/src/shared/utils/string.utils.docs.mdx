# String Utils

Utility functions for common string operations.

## `pluralize`

Appends `"s"` to a string when the count is anything other than 1.

```ts
import { pluralize } from '@team-hermes/react-components'

pluralize('item', 1) // "item"
pluralize('item', 0) // "items"
pluralize('item', 5) // "items"
```

## `generateSlug`

Converts a string into a URL-friendly slug by lowercasing, stripping non-alphanumeric characters, and replacing spaces with hyphens.

```ts
import { generateSlug } from '@team-hermes/react-components'

generateSlug('Hello World!') // "hello-world"
generateSlug('  Multiple   spaces  ') // "multiple-spaces"
generateSlug('Special @#$ chars') // "special--chars"
```
