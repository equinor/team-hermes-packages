# ErrorPanel

A standardised error display for API errors and unknown failures. It maps each `ApiError` variant to a human-readable title and always surfaces the `traceId` so support engineers can locate the failing request in logs.

<Primary />

## Usage

```tsx
import { ErrorPanel } from '@team-hermes/react-components'
```

```tsx
<ErrorPanel error={error} />
```

The `error` prop accepts any value. When an `ApiError` is passed, the panel renders a specific title based on the error kind and HTTP status, along with the trace ID. For non-API errors (plain `Error` instances, `Response` objects, or unknown values), a generic "Something went wrong" title is shown.
