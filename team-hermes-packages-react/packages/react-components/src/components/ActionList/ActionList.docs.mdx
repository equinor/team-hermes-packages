# ActionList

A panel component (`ActionListPanel`) that groups navigable list items (`ActionListItem`). Use it to present a set of related actions or links in a visually grouped card.

<Primary />

<Controls />

## Usage

```tsx
import { ActionListPanel, ActionListItem } from '@team-hermes/react-components'
```

```tsx
<ActionListPanel icon={dashboard} title="Quick Actions" description="3 items" variant="accent">
  <ActionListItem
    icon={home}
    title="Overview"
    description="View the main dashboard."
    linkTo="/overview"
    LinkComponent={RouterLink}
  />
  <ActionListItem
    icon={folder}
    title="Reports"
    description="Access reports and analytics."
    linkTo="/reports"
    LinkComponent={RouterLink}
  />
</ActionListPanel>
```
