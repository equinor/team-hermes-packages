# Popover

A popover overlay built on Base UI's Popover. It renders a positioned popup portal. Supports both uncontrolled (with a `trigger`) and controlled open state.

<Primary />

<Controls />

## Usage

- Use Popover for contextual content that should appear on demand next to a trigger.
- The popup is rendered through a portal, so it won't be clipped by overflow containers.
- Static compound members `Popover.Trigger` and `Popover.createHandle` are re-exported from Base UI for advanced composition.

```tsx
import { Popover } from '@team-hermes/react-components'
```

```tsx
<Popover trigger={<button>Open</button>}>
  <div style={{ padding: '1rem' }}>Popover body</div>
</Popover>
```

### Controlled mode

Manage the open state yourself when you need to open the popover programmatically:

```tsx
const [open, setOpen] = useState(false);

<button onClick={() => setOpen(true)}>Open</button>

<Popover open={open} setIsOpen={setOpen}>
  <div style={{ padding: '1rem' }}>Popover body</div>
</Popover>
```
