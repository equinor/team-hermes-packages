# FacetOption

A checkbox-style option used in faceted search filters. Each option displays a label, an optional result count, and a checkbox icon that toggles on click.

<Primary />

<Controls />

## Usage

- Use inside a list of filter categories to let users narrow down search results.
- Pass a `count` to show how many results match the option.
- Use `dimmed` to de-emphasise options with zero results.
- Use `indented` for child options in hierarchical facets.

```tsx
import { FacetOption } from '@team-hermes/react-components'
```

```tsx
<FacetOption label="Documents" count={142} checked={selected} onChange={setSelected} />
```
