# Message

Messages provide contextual feedback, status information, or guidance related to a workflow. They support visual types, optional titles, custom icons, and dismiss actions.

<Primary />

<Controls />

## Usage

- Use messages to communicate status, feedback, warnings, or errors close to the relevant content.
- Add a `title` when the message needs a short, scannable summary.
- Use `type` to match the message severity or purpose.
- Use `onDismiss` for temporary messages that users can close.
- Use `fullWidth` when the message should fill the available container.

```tsx
import { Message } from '@team-hermes/react-components'
```

```tsx
<Message type="success" title="Saved">
  Your changes have been saved.
</Message>
```
