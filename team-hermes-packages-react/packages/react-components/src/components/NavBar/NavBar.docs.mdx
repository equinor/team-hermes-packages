# NavBar

A top-level navigation bar that provides category-based navigation with dropdown menus, a color scheme popover, optional user information popover, and a help/support section. The application name displayed in the navbar is configured via `applicationConfig.name`.

<Primary />

<Controls />

## Usage

```tsx
import { NavBar } from '@team-hermes/react-components'
```

```tsx
<NavBar
  categories={[
    {
      title: 'Dashboard',
      basePath: 'dashboard',
      icon: dashboard,
      theme: 'success',
      links: [
        { href: '/overview', title: 'Overview', description: 'Main dashboard', icon: home },
        {
          href: 'https://eds.equinor.com',
          title: 'Design System',
          description: 'Browse the EDS documentation',
          icon: library_books,
          external: true,
        },
      ],
    },
  ]}
  LinkComponent={RouterLink}
  user={{ name: 'Ola Nordmann', email: 'ola@equinor.com', roles: ['admin'] }}
  logOut={() => signOut()}
  applicationConfig={{
    name: 'MyApp',
    roles: [{ value: 'admin', label: 'Admin' }],
    serviceNowLink: 'https://equinor.service-now.com',
    githubRepoName: 'equinor/team-hermes-packages',
  }}
/>
```

## Features

- **Category navigation** — Groups links under collapsible dropdown menus.
- **Active indicator** — Highlights the category matching the current route.
- **External links** — Links marked with `external: true` open in a new tab and show the EDS external link icon.
- **Color scheme popover** — A single button opens a popover for choosing **Auto**, **Light**, or **Dark**. The choice applies immediately with a short crossfade and is saved for later visits. **Auto** follows the OS preference live. The button shows the icon of the current choice and a tooltip on hover and keyboard focus.
- **User popover** — Displays user info and permissions when `user` is provided.
- **Support section** — Shows help/support dialog with ServiceNow and GitHub links.

## Examples

### Custom left content

Pass `leftContent` to replace the application icon, name link, and environment label.
The content retains the navbar's left-section layout. Omit the prop or pass `null`
to use the defaults; pass `false` to leave the section empty. Navigation and
right-side controls are unchanged.

```tsx
<NavBar
  categories={categories}
  LinkComponent={RouterLink}
  leftContent={<RouterLink to="/workspace">My workspace</RouterLink>}
/>
```

### Custom actions

Pass `customActions` to append actions after the color scheme button, user popover,
and support control. Each built-in control retains its existing prop-based
visibility. Custom actions also render when all built-in controls are hidden.

```tsx
<NavBar
  categories={categories}
  LinkComponent={RouterLink}
  customActions={<RouterLink to="/notifications">Notifications</RouterLink>}
/>
```

#### Version file

When `githubRepoName` is configured, the support dialog loads `/version.txt` from
the origin root, independent of the current route. For apps deployed under a
subpath, set `applicationConfig.versionUrl` to the version file's URL under the app's base path. The
published library does not infer the consuming app's Vite configuration:

```tsx
<NavBar
  categories={categories}
  LinkComponent={RouterLink}
  applicationConfig={{
    name: 'MyApp',
    githubRepoName: 'equinor/my-app',
    versionUrl: `${import.meta.env.BASE_URL}version.txt`,
  }}
/>
```

Serve a plain-text file containing `hash: <commit hash>`, `date: <commit date>`,
and `refs: <tag or branch>` on separate lines. Only `hash` is required; empty
`refs` falls back to the hash. Values may contain colons, whitespace is trimmed,
and blank or malformed lines are ignored. Failed requests, HTML responses, and
files without a hash are logged to the console and show `unknown` without a commit
link. The version also shows `unknown` while loading.

### External links

Set `external: true` on a link to render it as a plain anchor with `target="_blank"` and
`rel="noopener noreferrer"`, bypassing `LinkComponent` so the router does not intercept the
navigation. The chevron is replaced by the EDS external link icon, and screen readers announce
"Opens in a new tab".

### Localized color scheme popover

The color scheme button opens a popover with a radio group of three options. Its title also names
the button and the radio group. The selected option is the one checked. Each option applies immediately.
Escape, clicking outside, or the close button dismisses the popover.

- `colorSchemeToggleLabel` sets the button's accessible name and tooltip, and the popover title (default `"Color scheme"`).
- `colorSchemeOptionLabels` sets the visible option labels (defaults `"Auto"`, `"Light"`, and `"Dark"`).
  Omitted labels keep their defaults.
- `autoColorSchemeToggleLabel` describes the Auto option in its tooltip and accessible description
  (default `"Follow system color scheme"`).

```tsx
<NavBar
  categories={categories}
  LinkComponent={RouterLink}
  colorSchemeToggleLabel="Fargemodus"
  autoColorSchemeToggleLabel="Følg systemets fargevalg"
  colorSchemeOptionLabels={{ auto: 'Automatisk', light: 'Lys', dark: 'Mørk' }}
/>
```
