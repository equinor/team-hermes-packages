# team-hermes-packages-react

A React component library providing shared code and components for Team Hermes projects.

Components are previewed and documented via Storybook. The package is hosted on GitHub Packages for internal consumption.

## Installation

### Temporary installation from GitHub Packages:

```bash
gh api -H "Accept: application/octet-stream" repos/equinor/team-hermes-packages/releases/assets/$(gh api repos/equinor/team-hermes-packages/releases/tags/team-hermes-packages-react-v1.1.0 --jq '.assets[0].id') > /tmp/team-hermes-packages-react-1.1.0.tgz && yarn add @equinor/team-hermes-packages-react@/tmp/team-hermes-packages-react-1.1.0.tgz
```

Import the stylesheet in your app's entry point:

```ts
import '@equinor/team-hermes-packages-react/style.css'
```

## Stack

- React
- TypeScript
- Vite+ (unified toolchain: Vite, Vitest, Oxlint, Oxfmt)
- Storybook for component development and documentation
