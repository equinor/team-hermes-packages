# team-hermes-packages-react

A React component library providing shared code and components for Team Hermes projects.

Components are previewed and documented via Storybook. The package is hosted on GitHub Packages for internal consumption.

## Installation

```bash
vp add @equinor/team-hermes-packages-react@git+https://github.com:equinor/team-hermes-packages#[release-version-tag]

#example
vp add @equinor/team-hermes-packages-react@git+https://github.com:equinor/team-hermes-packages#^1.0.0
```

Import the stylesheet in your app's entry point:

```ts
import 'team-hermes-packages-react/style.css'
```

## Stack

- React
- TypeScript
- Vite+ (unified toolchain: Vite, Vitest, Oxlint, Oxfmt)
- Storybook for component development and documentation
