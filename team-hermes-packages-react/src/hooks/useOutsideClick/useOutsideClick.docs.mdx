# useOutsideClick

A hook that detects clicks outside one or more elements and invokes a callback. Useful for closing dropdowns, popovers, or modals when the user clicks elsewhere.

## Usage

```tsx
import { useRef } from 'react'
import { useOutsideClick } from 'team-hermes-packages-react'

function Dropdown({ onClose }: { onClose: () => void }) {
  const menuRef = useRef<HTMLDivElement>(null)
  const triggerRef = useRef<HTMLButtonElement>(null)

  useOutsideClick([menuRef, triggerRef], onClose)

  return (
    <>
      <button ref={triggerRef}>Toggle</button>
      <div ref={menuRef}>Menu content</div>
    </>
  )
}
```

## API

## Notes

- The hook listens on the `mousedown` event so the callback fires before `click`, matching native dropdown behaviour.
- Pass multiple refs when the trigger and the popup are separate DOM trees (e.g. portalled content).
- If `refs` is empty, the callback is never invoked.
