# Number Utils

Utility functions for formatting numbers and file sizes.

---

## `formatFileSize`

Formats a byte count as a human-readable file size string in KB or MB.

```ts
import { formatFileSize } from '@team-hermes/react-components'

formatFileSize(512) // "0.5 KB"
formatFileSize(1048576) // "1.0 MB"
formatFileSize(2621440) // "2.5 MB"
```

## `formatNumberToLocale`

Formats a number with spaces as thousand separators and no decimal places. Non-integer values are rounded to the nearest whole number.

```ts
import { formatNumberToLocale } from '@team-hermes/react-components'

formatNumberToLocale(1234567) // "1 234 567"
formatNumberToLocale(99.7) // "100"
formatNumberToLocale(null) // ""
```
