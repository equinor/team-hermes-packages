# Tabs

Styled wrappers around Base UI's Tabs primitives. They provide the Team Hermes tab list, active indicator, tab button, and panel styling while keeping the Base UI composition model.

<Primary />

<Controls />

## Usage

- Use Tabs to switch between related sections without leaving the current page.
- Tabs are controlled: provide `value` and update it from `onValueChange`.
- Keep tab labels short and use a clear `aria-label` on `TabsList` when there is no visible heading.
- Use `className` on the individual primitives for small layout adjustments, such as constrained or scrollable tab lists.

```tsx
import { Tab, TabPanel, TabsList, TabsRoot, type TabValue } from 'team-hermes-packages-react'
```

```tsx
const [value, setValue] = useState<TabValue>('overview')

;<TabsRoot value={value} onValueChange={(nextValue) => setValue(nextValue)}>
  <TabsList aria-label="Project sections">
    <Tab value="overview">Overview</Tab>
    <Tab value="activity">Activity</Tab>
  </TabsList>

  <TabPanel value="overview">Overview content</TabPanel>
  <TabPanel value="activity">Activity content</TabPanel>
</TabsRoot>
```
