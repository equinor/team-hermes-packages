# DataGrid

A feature-rich, editable data grid built on [TanStack Table](https://tanstack.com/table) with virtualised rows and columns, drag-to-reorder headers, clipboard operations, undo/redo, and inline cell editing.

## Quick start

```tsx
import { AttributeType, DataGrid, useDataGrid } from '@team-hermes/react-components'
import type { ColumnDef } from '@tanstack/react-table'

type Row = { uid: string; name: string; depth: number }

const columns: ColumnDef<Row>[] = [
  { id: 'name', accessorKey: 'name', header: 'Name', meta: { dataType: AttributeType.TEXT } },
  { id: 'depth', accessorKey: 'depth', header: 'Depth', meta: { dataType: AttributeType.NUMBER } },
]

function MyGrid() {
  const [data, setData] = useState<Row[]>(initialRows)

  const { table } = useDataGrid({
    data,
    columns,
    getRowId: (row) => row.uid,
    meta: { setData },
  })

  return <DataGrid table={table} />
}
```

### What `useDataGrid` provides automatically

- `columnResizeMode: 'onChange'` and `columnResizeDirection: 'ltr'`
- `getCoreRowModel()`, `getFilteredRowModel()`, `getFacetedUniqueValues()`, `getSortedRowModel()`
- Attaches the built-in `filterFn` to every column that has `meta.dataType` set (unless a custom `filterFn` is already present)
- Injects a hidden `validation_column` and registers the `validationFilter` when `meta.validationErrors` or `meta.validationWarnings` is provided

All options are pass-through to TanStack Table, so you can still provide `manualFiltering`, `onSortingChange`, `state`, etc.

### Server-side example

```tsx
const { table } = useDataGrid({
  data: measurements,
  columns,
  getRowId: (row) => row.analysis_id,
  manualFiltering: true,
  manualPagination: true,
  manualSorting: true,
  rowCount: totalItems,
  onColumnFiltersChange: setColumnFilters,
  onSortingChange: setOrderBy,
  onPaginationChange: setPagination,
  state: { columnFilters, sorting: orderBy, pagination },
  meta: { validationErrors: {} },
})
```

### Advanced: raw `useReactTable`

If you need full control, you can still pass a table instance directly. You are responsible for providing all row models, `filterFn` per column, and the validation column yourself:

```tsx
import { getCoreRowModel, getFilteredRowModel, useReactTable } from '@tanstack/react-table'
import { filterFn } from '@team-hermes/react-components'

const table = useReactTable({
  data,
  columns: columns.map((c) => ({ ...c, filterFn })),
  columnResizeMode: 'onChange',
  columnResizeDirection: 'ltr',
  getCoreRowModel: getCoreRowModel(),
  getFilteredRowModel: getFilteredRowModel(),
  getSortedRowModel: getSortedRowModel(),
  getFacetedUniqueValues: getFacetedUniqueValues(),
  getRowId: (row) => row.uid,
  meta: { setData },
})

<DataGrid table={table} />
```

## Table meta

Supply these on `useDataGrid({ meta: { ... } })` (or `useReactTable` if using the advanced API). All properties are documented with JSDoc in the `TableMeta` augmentation in `DataGrid.types.tsx`.

```tsx
meta: {
  setData,              // Required for editing — state setter
  defaultRowFactory,    // Creates new rows (preferred)
  defaultRowValue,      // Static template cloned for new rows
  onCellsChanged,       // Callback after cell mutations
  validationErrors,     // Keyed as "[rowIndex].columnId"
  validationWarnings,   // Same format as errors
  validationKeyPrefix,  // 'rowIndex' | 'rowId'
  addColumn,            // Callback when column added
  removeColumn,         // Callback when column removed
}
```

## Column meta

Extend each column definition with `meta` to control behaviour per-column. All properties are documented with JSDoc in the `ColumnMeta` augmentation in `DataGrid.types.tsx`.

```tsx
{
  id: "depth",
  accessorKey: "depth",
  header: "Depth",
  meta: {
    dataType: AttributeType.NUMBER,
    editable: true,
    unit: "m",
    isSortable: true,
    minValue: 0,
    maxValue: 10000,
  },
}
```

## Nested values (dot syntax)

DataGrid supports nested object properties using dot-notation in `accessorKey`. This works across all features including editing, copy/paste, undo/redo, and filtering:

```tsx
// Data shape
type Row = {
  uid: string
  site: { country_identifier_source: string; area: string }
  measurement: { value: number; unit: string }
}

// Column definitions
const columns: ColumnDef<Row>[] = [
  {
    id: 'country_identifier_source',
    accessorKey: 'site.country_identifier_source',
    header: 'Country',
    meta: { dataType: AttributeType.TEXT, editable: false },
  },
  {
    id: 'area',
    accessorKey: 'site.area',
    header: 'Area',
    meta: { dataType: AttributeType.TEXT, editable: true },
  },
  {
    id: 'measurement_value',
    accessorKey: 'measurement.value',
    header: 'Measurement',
    meta: { dataType: AttributeType.NUMBER, editable: true, unit: 'm' },
  },
]
```

Under the hood, DataGrid uses `getNestedValue()` for reads and `deepSet()` for writes, so arbitrarily deep paths like `"a.b.c"` work correctly.
