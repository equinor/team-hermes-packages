# QuickAccessButton

A card-style button that provides quick navigation to key areas of the application. Supports color themes, locked states, and custom link components.

<Primary />

<Controls />

## Usage

```tsx
import { QuickAccessButton } from '@team-hermes/react-components'
```

```tsx
<QuickAccessButton
  icon={dashboard}
  label="Dashboard"
  description="View overview"
  linkTo="/dashboard"
  variant="accent"
  LinkComponent={RouterLink}
/>
```
