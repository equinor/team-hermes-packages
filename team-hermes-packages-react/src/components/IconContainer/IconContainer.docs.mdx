# IconContainer

A themed container for displaying an EDS icon, text, or both. Useful for avatars, status indicators, and compact visual labels.

<Primary />

<Controls />

## Usage

- Use `IconContainer` to give icons a themed background with consistent sizing.
- When both `icon` and `text` are provided, the container doubles in width to fit both.
- Use the `loading` prop to replace content with a spinner during async operations.

```tsx
import { IconContainer } from 'team-hermes-packages-react'
```

```tsx
<IconContainer icon={save} variant="success" shape="circle" />
```
