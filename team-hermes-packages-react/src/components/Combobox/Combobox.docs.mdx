# Combobox

A searchable dropdown selector built on Base UI's Combobox. Supports single and multi-select modes with type-ahead filtering.

<Primary />

<Controls />

## Usage

- Use Combobox when the list of options is large enough that users benefit from filtering by typing.
- For a small fixed set of options without search, consider a plain select or `MenuCheckboxList`.
- In multi-select mode, selected items render as removable chips inside the input.

```tsx
import { Combobox, type ComboboxItem } from 'team-hermes-packages-react'
```

```tsx
const items: ComboboxItem[] = [
  { label: 'Apple', value: 'apple' },
  { label: 'Banana', value: 'banana' },
]

;<Combobox items={items} value={selected} onChange={setSelected} placeholder="Pick a fruit" />
```
