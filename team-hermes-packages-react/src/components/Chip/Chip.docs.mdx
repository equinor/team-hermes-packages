# Chip

Chips are compact elements that represent an attribute, input, or action. They allow users to filter content, make selections, or trigger actions.

<Primary />

<Controls />

## Usage

- Use chips to represent tags, filters, or selectable attributes.
- Chips can be interactive (clickable) to trigger actions like filtering or navigation.
- Add a dismiss button when the chip represents a removable selection.
- Use tooltips to provide additional context when chip labels are abbreviated.

```tsx
import { Chip } from "team-hermes-packages-react";
```

```tsx
<Chip theme="accent" fontSize="sm" onDismiss={() => removeFilter(id)}>
  Active filter
</Chip>
```
